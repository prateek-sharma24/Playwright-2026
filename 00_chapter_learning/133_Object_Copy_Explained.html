Why does changing b also change a?

Big idea: a and b are two labels pointing to the same object. They are not two separate objects.

The code

let a = { status: "pass" };
let b = a; // copy the reference
b.status = "fail";
console.log(a.status);

Picture it like two name tags on one toy box

a
“this box”
b
“this box too”
⟶
One shared object
status: "fail"
  1. a gets a new object with status: "pass".
  2. b = a copies the object's address, like copying its location—not making another box.
  3. b.status = "fail" changes the shared object.
  4. Looking through a finds that same changed object.

Output: fail

To make a separate, shallow copy of this simple object, you could write let b = { ...a };. Then changing b.status would not change a.status.
